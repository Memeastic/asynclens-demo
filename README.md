# AsyncLens Demo

This repository contains a small demo of AsyncLens (instrumentation + collector + dashboard).

Quick start

1. Install Node.js (https://nodejs.org) if you don't have it.
2. In the project folder run:

   npm install
   npm start

3. Open in your browser:

   http://localhost:3000/demo.html
   http://localhost:3000/dashboard.html

Click the buttons on the demo page to generate async events and watch the dashboard update in real time.
